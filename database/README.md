# База законодательства

Проверенная база пока не опубликована. Не использовать пустую или непроверенную базу для обновления приложения. Формат: объект с server, version, articles; каждая запись содержит id, document, number, text, source, status, sanctions. sanctions — массив, пустой только при подтверждённом отсутствии санкций.
