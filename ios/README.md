# RMRP Legal 3.0 для iPhone

В ZIP для установки база уже встроена. При сборке из GitHub сначала скопируйте последнюю базу в ресурсы приложения.

```bash
# Из корня репозитория:
cp data/articles.json ios/Sources/RMRPLegal/articles.json
cd ios
xtool dev run --configuration release --usb
```

Приложение для iOS 17+ проверяет последнюю базу в GitHub при открытии, если прошло 24 часа с последнего успешного обновления. При недоступности сети сохраняется прежняя копия.

GitHub Actions ежедневно проверяет открытые источники RMRP и публикует изменившуюся базу. Данные для чтения включают текст публичных сообщений форума. Изображения и другие вложения в офлайн-базу не входят.
